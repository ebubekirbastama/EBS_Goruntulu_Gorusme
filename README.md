# ⚡ EBS LiveLink

> Real-Time Wireless Video Call, Screen Share & Media Transfer Platform

EBS LiveLink; Android cihazlar ve masaüstü bilgisayarlar arasında ultra hızlı görüntülü görüşme, ekran paylaşımı, medya aktarımı ve gerçek zamanlı iletişim sağlayan profesyonel bir kablosuz haberleşme platformudur.

Sistem tamamen yerel ağ (Wi-Fi / Hotspot) üzerinde çalışır ve herhangi bir bulut sunucusuna ihtiyaç duymaz.

# 🛠️ Kurulum

## Android

Android Studio ile aç:

```bash
gradlew assembleDebug
```

---

## Masaüstü

```bash
pip install customtkinter
pip install pillow
pip install opencv-python
pip install pyqrcode
pip install pyaudio
```

Çalıştır:

```bash
python server.py
```
